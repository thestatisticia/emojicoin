### Next Steps:

1. **Start the Development Server**:
   ```bash
   npm run dev
   ```

2. **Connect Your Wallet**:
   - Open the app in your browser
   - Connect your wallet (RainbowKit will prompt you)
   - Make sure you're connected to QIE Network (Chain ID: 1990)

3. **Create Your First Token**:
   - Fill in the token creation form
   - Choose an emoji symbol
   - Set name, supply, and decimals
   - Click "Launch Into Orbit"

4. **Add Liquidity**:
   - Go to "My Tokens" tab
   - Click "Add Liquidity" on your token
   - Approve the token first
   - Then supply liquidity (Token + QIE)

5. **Swap Tokens**:
   - Go to "Swap" tab
   - Select a token to swap
   - Enter amounts and execute swap
